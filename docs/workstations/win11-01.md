# WIN11-01 - Windows Workstation

## Purpose

WIN11-01 is currently the only Windows 11 workstation within the lab network and acts as an endpoint for testing services delivered by the DC and File Server.

The machine is joined to the `ad.home.arpa` Active Directory domain and is used to test domain authentication, Group Policy application, user management and workstation security configurations.

## Network Configuration

| Setting | Configuration |
|---|---|
| Hostname | `WIN11-01` |
| IP address | `192.168.10.20` |
| Subnet mask | `255.255.255.0` |
| Default gateway | `192.168.10.1` |
| Preferred DNS | `192.168.10.10` |
| Network | Lab network (`192.168.10.0/24`) |

The workstation uses OPNsense as its default gateway and WINDC-01 as its preferred DNS server.

DNS is directed through the domain controller to maintain proper Active Directory name resolution.

## Active Directory Integration

| Setting | Configuration |
|---|---|
| Domain | `ad.home.arpa` |
| NetBIOS domain | `HOME` |
| Domain controller | `WINDC-01` |
| Computer account OU | Workstations |
| Standard user account | `lab.user` |
| Administrative account | `lab.admin` |

Domain authentication has been tested using the standard `lab.user` account as well as Sales and Marketing user accounts.

## Group Policy

A workstation baseline policy has been created and linked to the Workstations Organisational Unit.

### Implemented GPO

| GPO | Scope | Status |
|---|---|---|
| LAB - Workstation Baseline | Workstations OU | Implemented |

The initial configuration includes:

- Interactive logon: Don't display last signed-in - enabled.

This setting prevents the last signed in user from being displayed on the Windows sign in screen.

The policy was validated following a workstation restart.
